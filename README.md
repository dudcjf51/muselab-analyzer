# Muse.lab 스타일 분석 (내부용)

얼굴·퍼스널컬러·체형·골격을 **브라우저 안에서만** 분석하고, 고객용 스타일북 PDF를 만드는 도구입니다.

- 사진은 기기 밖으로 전송되지 않습니다. 서버도, AI 요금도 없습니다.
- 분석 엔진: Google MediaPipe Face Mesh / Pose (Apache-2.0, `vendor/` 폴더에 포함)
- 결과는 측정값 기반의 1차 참고 결과이며, 최종 유형은 컨설턴트가 확정합니다.

## 폴더 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 스타일북 디자인 |
| `app.js` | 분석 로직 (얼굴 비율, 피부색, 체형 비율, 골격 점수) |
| `data.js` | 결과 설명 문구, 퍼스널컬러 팔레트, 질문 (자유롭게 수정 가능) |
| `vendor/` | 분석 엔진 파일 (수정하지 마세요) |

## 배포 (GitHub Pages, 무료)

1. GitHub에서 새 저장소를 만듭니다 (예: `muselab-analyzer`).
2. **Add file → Upload files**로 이 폴더 안의 모든 파일과 `vendor` 폴더를 통째로 끌어다 놓고 **Commit changes**.
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**.
4. 1~2분 뒤 `https://<아이디>.github.io/muselab-analyzer/` 주소로 접속합니다.

Vercel로 배포해도 됩니다 (홈페이지와 같은 방법, 설정 변경 없음).

## 사용 순서

1. 고객 이름, 여성/남성 기준 선택, 동의 체크
2. 얼굴 정면 사진, 전신 정면 사진 (태블릿에서는 바로 촬영, PC에서는 파일 선택)
3. 흰 종이가 함께 찍혔다면 **흰색 기준 찍기** → 사진 속 흰 부분 터치 (색 보정)
4. 골격 질문 6개, 피부 톤 질문 3개 답하기
5. **분석하기** → 결과 확인 → 최종 유형 선택 → 코멘트 작성
6. **스타일북 미리보기 · PDF 저장** → 인쇄 창에서 'PDF로 저장', A4, 배경 그래픽 켜기
7. 다음 고객은 **새 고객 시작** (사진과 결과가 모두 지워집니다)

## 촬영 팁 (정확도에 가장 큰 영향)

- 무채색 배경, 주광색 조명(5000~5500K) 양쪽 45도, 창문 빛·형광등은 차단
- 얼굴: 머리를 넘기고 화장 최소, 흰 케이프, 정면
- 전신: 몸에 맞는 무지 상의 + 일자 바지, 발 어깨너비, **팔을 몸에서 살짝 떨어뜨리기**
- 같은 위치·같은 조명으로 매번 촬영 (바닥에 서는 자리 표시)

## 판정 기준 조정

- 체형·얼굴형 기준값은 `app.js`의 `analyzeBody`, `analyzeFace` 함수 안 숫자입니다.
- 퍼스널컬러 기준은 `decideSeason` 함수입니다.
- 실제 고객 10~20명의 측정값과 컨설턴트 판정을 비교해 숫자를 조정하면 정확도가 올라갑니다.
